T: Theory
P: A robot uses a camera to record the corridor it is travelling along and measures the number of successful deliveries per hour. In PEAS, how are these two elements classified?
a) Camera: performance measure. Successful deliveries per hour: actuator.
b) Camera: actuator. Successful deliveries per hour: initial state.
c) Camera: sensor. Successful deliveries per hour: performance measure.
d) Camera: environment. Successful deliveries per hour: sensor.
R: c
E: PEAS = Performance, Environment, Actuators, Sensors. La cámara percibe, así que es un sensor. Las entregas por hora miden lo bien que lo hace: medida de rendimiento.

P: What does BFS guarantee in a finite graph if all steps have the same cost and a goal is reachable?
a) It returns a minimum-cost goal even when step costs differ.
b) It returns the goal with the fewest successors.
c) It guarantees a minimum only when it uses an admissible heuristic.
d) It returns a goal at minimum depth and therefore at minimum cost.
R: d
E: BFS explora por niveles, así que encuentra la meta menos profunda. Si todos los pasos cuestan lo mismo, menos pasos es también menos coste.

P: An agent updates Q using Q-learning and explores with ε-greedy. Which future value does its TD target use when the next state is non-terminal?
a) Always the Q-value of the action actually taken next.
b) The largest reward received so far.
c) The maximum Q-value over actions in the next state.
d) The average Q-value in the current state.
R: c
E: Q-learning es off-policy: usa el máximo Q del estado siguiente aunque luego no se tome esa acción. El Q de la acción realmente tomada es lo que usa SARSA.

P: When maximising fitness, what distinguishes simulated annealing from strict hill climbing?
a) Simulated annealing accepts only strict improvements.
b) Hill climbing accepts every move that reduces fitness when the temperature is high.
c) Both methods require a population of candidate solutions.
d) Simulated annealing can accept a move that reduces fitness, with a probability that depends on temperature.
R: d
E: El enfriamiento simulado puede aceptar un empeoramiento con probabilidad e^(Δ/T). Hill climbing estricto solo acepta mejoras.

T: Problem formulation
P: A machine cuts rolls. When a piece of the required length is delivered, it is removed from stock and outstanding demand for that length decreases. Which representation distinguishes states with different future possibilities?
a) Only the total length of material in stock.
b) The total length ordered and the last action.
c) A multiset of lengths in stock and a multiset of lengths still required.
d) Only the number of cuts already made.
R: c
E: Importa qué longitudes quedan y cuáles faltan, con repeticiones: por eso son multiconjuntos. Con solo el total no sabes si puedes servir una pieza concreta.

P: A, B and C are presentations assigned to slots 1, 2 or 3. B must be earlier than C. A and C may share a slot, but A and B cannot. Which constraints model these requirements?
a) B<C and A≠C.
b) B<C, A≠B and A≠C.
c) B<C and A≠B.
d) B≤C and A≠B.
R: c
E: B antes que C es B<C. A y B no pueden compartir: A≠B. A y C sí pueden, así que NO se pone A≠C.

P: In an MDP, taking the reset action in s leads to base with probability 0.8 and to a terminal state with probability 0.2. The rewards paid on these transitions are −1 and −4 respectively. Which representation retains this information?
a) A certain transition to base with r=−1.6.
b) Two actions selected by the agent with probabilities 0.8 and 0.2.
c) A transition to the terminal state with probability 1 and r=−4.
d) P(base given s, reset)=0.8 with r=−1. P(terminal given s, reset)=0.2 with r=−4.
R: d
E: Una acción estocástica guarda cada resultado con su probabilidad y su recompensa, sin mezclarlos. La media (−1.6) pierde información.

P: Q(s,a)=2, α=0.25, γ=0.8 and r=1. At the non-terminal state s′, max Q=5 and the next action actually taken has Q=2. What new values do Q-learning and SARSA return, in that order?
a) 5 and 2.6.
b) 2.75 and 2.15.
c) 2 and 2.
d) 2.15 and 2.75.
R: b
E: Q-learning: 2 + 0.25·(1 + 0.8·5 − 2) = 2.75. SARSA usa el Q de la acción tomada: 2 + 0.25·(1 + 0.8·2 − 2) = 2.15.

P: The Loopover action code uses bits 0–1 for the row, bits 2–3 for the column and bit 4 set to 1 for the + sign. Which decimal value encodes 13+?
a) 29.
b) 23.
c) 30.
d) 13.

P: For a Loopover board, the summed toroidal distances are Σdf=6 along the vertical axis and Σdc=12 along the horizontal axis. A rotation moves up to four tiles one step along its axis. What are the raw and admissible Manhattan heuristic values, respectively?
a) 18 and 3.
b) 18 and 2.
c) 18 and 5.
d) 3 and 18.
R: a
E: Sin dividir: 6+12 = 18. Admisible: max(ceil(6/4), ceil(12/4)) = max(2,3) = 3. Se usa el máximo porque una acción mueve a la vez una fila y una columna.

P: Two A* nodes contain the same board. The old node has g=11 and the new one has g=8. If the better path is adopted, what must be updated?
a) Update g, the parent, the action used to reach the node and the priority g+h.
b) Update g and leave the parent unchanged.
c) Update only the board's h-value.
d) Discard the new node because the board's identity has not changed.
R: a
E: Si el camino nuevo es mejor, cambia todo lo del camino: g, el padre, la acción y f = g+h. La h no cambia, porque el tablero es el mismo.

P: Project example. A* and UCS find paths of cost 9 on the same board. A* expands 75 nodes and UCS expands 150. Which conclusion is supported?
a) A* reduced the solution cost by 50%.
b) A* expanded 50% fewer nodes on that board, and the solution costs were equal.
c) A* takes half as long on every board.
d) UCS used twice as much memory in every experiment.
R: b
E: 75 es la mitad de 150: 50 % menos nodos en ESE tablero, con el mismo coste. Los datos no dicen nada del tiempo ni de la memoria en general.
