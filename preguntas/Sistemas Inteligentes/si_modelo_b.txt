T: Theory
P: In a turn-based dice game, the state consists of the board, whose turn it is and the dice results. All players can see this information. How is the environment classified in terms of observability, transitions and agents?
a) Fully observable, deterministic and single-agent.
b) Fully observable, stochastic and multi-agent.
c) Partially observable, deterministic and single-agent.
d) Partially observable, stochastic and single-agent.
R: b
E: Todos ven el estado completo: totalmente observable. Los dados lo hacen estocástico y hay varios jugadores: multiagente.

P: A* uses h(S)=6 and h(A)=2, and the edge S→A has cost 3. What does this single edge establish?
a) The heuristic necessarily overestimates h*(S).
b) The heuristic is consistent throughout the graph.
c) Consistency fails on S→A because 6>3+2.
d) The graph has negative edge costs.
R: c
E: Consistencia: h(S) ≤ coste + h(A). Aquí 6 > 3+2 = 5, así que falla en esa arista. Una arista no basta para saber si h sobrestima h*.

P: Once a variable has been selected, what does the least-constraining-value (LCV) heuristic select?
a) The largest numerical value, irrespective of the constraints.
b) The value that rules out the fewest possibilities for unassigned neighbouring variables.
c) The variable with the smallest domain.
d) The value that immediately rules out the most possibilities.
R: b
E: LCV elige el VALOR que menos opciones quita a las vecinas. Elegir la variable con menor dominio es MRV.

P: A MAX node has secured α=8. While visiting a MIN child, it sees that child's first leaf has value 6. What follows for the MIN branch?
a) The MIN node has an exact value of 6.
b) The remaining leaves all have value 6 by consistency.
c) The MIN node will necessarily increase α.
d) The remaining leaves of that MIN node can be pruned.
R: d
E: El MIN vale como mucho 6, y MAX ya tiene 8 asegurado: β=6 ≤ α=8, se corta. El valor exacto del MIN no se sabe.

P: What is the effect of α=0 on a Q-learning update if the TD target differs from the current value?
a) The discount factor automatically becomes zero.
b) Q is replaced with the target.
c) Q keeps its previous value in that update.
d) Q becomes equal to the reward.
R: c
E: Q ← Q + α·(objetivo − Q). Con α=0 no se suma nada: Q se queda igual.

P: A vehicle reaches a junction with some battery charge remaining. The tunnel requires two units of charge and a charging stop can be used once. Which state representation is sufficient?
a) The junction, the remaining charge and whether the charging stop has already been used.

P: There is one variable Rᵢ per column for placing queens. For columns i≠j, which constraints prevent queens from sharing a row or diagonal?
a) Only Rᵢ≠Rⱼ.
b) Rᵢ+i=Rⱼ+j.
c) Rᵢ≠Rⱼ and abs(Rᵢ−Rⱼ)≠abs(i−j).
d) Rᵢ≠Rⱼ and abs(Rᵢ−Rⱼ)=abs(i−j).

P: An agent at S can stop for a reward of 3, or advance to T for a reward of 1. From T, the only action ends the episode with a reward of 8 or −2, each with probability 0.5. With V₀=0 and γ=0.5, what is V₂(S) and which action achieves it? Use synchronous updates.
![From Action To Prob. Reward; S stop Terminal 1 3; S advance T 1 1; T act Terminal 0.5 8; T act Terminal 0.5 -2](img/modelo_b_13.png)
a) 4, advance.
b) 6, advance.
c) 3, advance.
d) 3, stop.
R: d
E: V₁(T) = 0.5·8 + 0.5·(−2) = 3. V₂(S) = max(parar 3, avanzar 1 + 0.5·3 = 2.5) = 3, parar.
