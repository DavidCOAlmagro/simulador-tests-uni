T: Theory
P: A collection robot observes only its current cell and updates an internal map after moving. Which architecture best describes its use of the map?
a) An agent that observes the entire world at each step.
b) A model-based agent with an internal state.
c) A simple reflex agent with no memory.
d) An agent that necessarily uses reinforcement learning.
R: b
E: Solo ve su casilla y mantiene un mapa interno: agente basado en modelos, con estado interno.

P: The frontier contains A(g=9,h=1), B(g=3,h=4) and C(g=2,h=6). Which node does A* remove first?
a) C.
b) B.
c) There is insufficient information.
d) A.
R: b
E: A* saca la menor f = g+h: A=10, B=7, C=8. Sale B.

P: After assigning X=2 in a CSP with X≠Y and X≠Z, forward checking is applied. D(Y)={1,2,3} and D(Z)={2}. What happens?
a) Y is reduced to {1,3}, Z becomes empty and the search backtracks.
b) The values 1 and 3 are removed from Y.
c) Y becomes empty and Z remains {2}.
d) Z remains {2} until it is assigned a value.
R: a
E: X=2 quita el 2 de sus vecinas: Y={1,3} y Z=∅. Dominio vacío, así que se vuelve atrás.

P: If alpha–beta and full minimax search the same tree to the same search horizon, what is preserved?
a) The pruning order for every order of successors.
b) The need to expand every state.
c) The minimax value at the root.
d) The number of leaves evaluated.
R: c
E: Alfa-beta da el MISMO valor minimax en la raíz; lo que cambia es cuántas hojas se miran.
Fuente: Modelo C, pregunta 4.

P: An ε-greedy policy chooses uniformly among four actions when exploring, including the one greedy action. If ε=0.4, what is the probability of selecting the greedy action?
a) 0.10.
b) 0.40.
c) 0.60.
d) 0.70.
R: d
E: Explota: 1−0.4 = 0.6. Al explorar también puede tocarle: 0.4·(1/4) = 0.1. Total 0.7.
Fuente: Modelo C, pregunta 5.

P: With binary encoding and neighbours at Hamming distance 1, when does strict hill climbing stop?
a) Only when it certifies the global maximum.
b) When any neighbour has equal fitness, even if another is better.
c) As soon as any neighbour is worse, even if another is better.
d) When no neighbour has higher fitness.
R: d
E: Hill climbing estricto se para cuando ningún vecino es mejor. Puede ser solo un óptimo local.

P: Regions U and V are adjacent. Region W touches neither. Each can be red or green. Which CSP expresses only the rule that adjacent regions have different colours?
a) D(U)=D(V)=D(W)={red,green} and all three are equal.
b) D(W)=∅ and U≠V.
c) D(U)=D(V)=D(W)={red,green} and U≠V.

P: A schedule assigns four operations to two machines. Each operation goes to one machine, and the largest workload is to be minimised. Which local-search model fits?
a) An assignment vector, a neighbour obtained by moving one operation, and the number of machines used as the objective.
b) The previous best time as the state, without storing any assignments.
c) An assignment vector, a neighbour obtained by moving one operation, and the maximum workload as the objective.
d) An ordered list of durations, a neighbour obtained by removing one operation, and the sum of durations as the objective.

E: Estado = a qué máquina va cada operación. Vecino = mover una. Objetivo = la carga máxima, que es lo que se quiere minimizar.

P: Q(s,a)=4, α=0.5, γ=0.5 and r=-1. At the non-terminal state s′, max Q=6 and the next action actually taken has Q=2. What new values do Q-learning and SARSA return, in that order?
a) 2 and 3.
b) 2 and 0.
c) 4 and 4.
d) 3 and 2.
R: d
E: Q-learning: 4 + 0.5·(−1 + 0.5·6 − 4) = 3. SARSA: 4 + 0.5·(−1 + 0.5·2 − 4) = 2.

P: The Loopover action code uses bits 0–1 for the row, bits 2–3 for the column and bit 4 set to 1 for the + sign. Which decimal value encodes 32+?
a) 28.
b) 30.
c) 11.
d) 27.
R: d
E: código = fila + 4·columna + 16 si es +. 32+ → 3 + 4·2 + 16 = 27.
Fuente: Modelo C, pregunta 16.

P: For a Loopover board, the summed toroidal distances are Σdf=8 along the vertical axis and Σdc=14 along the horizontal axis. A rotation moves up to four tiles one step along its axis. What are the raw and admissible Manhattan heuristic values, respectively?
a) 22 and 2.
b) 22 and 6.
c) 22 and 4.
d) 4 and 22.
R: c
E: Sin dividir: 8+14 = 22. Admisible: max(ceil(8/4), ceil(14/4)) = max(2,4) = 4 (3.5 se redondea hacia arriba).

P: In the lab version of Loopover, an action rotates the row first and then the column. What is the physical order for undoing it?
a) Repeat the original rotations in the same direction.
b) Undo the column rotation first, then the row rotation.
c) Use two row rotations in either order.
d) Undo the row rotation first, then the column rotation.
R: b
E: Para deshacer se va al revés: primero la columna (lo último que se hizo) y después la fila.

P: Project example. Heuristic H expands 60 nodes and takes 32 ms. Heuristic J expands 90 nodes and takes 22 ms. Both return the same solution cost. Which statement matches the results?
a) H expands fewer nodes and J runs faster on this instance.
b) H and J require exactly the same computational effort.
c) J returns a lower-cost solution.
d) H runs faster because it expands fewer nodes.
R: a
E: H expande menos nodos, pero J tarda menos en esta instancia. El coste de la solución es el mismo.
